# 仮想トレード練習場

実際のお金を使わずに、日本株・米国株・ETF・債券ETF・金・FX・暗号資産（48銘柄）の売買を練習するアプリです。

- 価格は Yahoo Finance から30分ごとに自動で取得します（APIキー不要）。
- 約定のタイミングは本物に合わせています（東証・米国市場の取引時間、単元未満株は次の寄り付き、FXは平日24時間、暗号資産は24時間365日）。
- 注文するときに「答え合わせ（1日後・1週間後など）」と「理由」を残すと、期限に当たり・外れと損益を自動で判定します。
- 記録はブラウザの中だけに保存されます（設定画面から書き出し・読み込みできます）。

## ファイル

| ファイル | 役割 |
|---|---|
| `fetch_prices.py` | 価格を取得して `site/data.json` を作る。銘柄の追加・削除はここの `INSTRUMENTS` |
| `site/index.html` | アプリの画面 |
| `site/engine.js` | 売買の判定（取引時間・約定・コスト・答え合わせ）。コストの目安は先頭の `COSTS` |
| `.github/workflows/pages.yml` | 30分ごとに価格を取得してアプリを公開する |

## 注意

- 練習用のシミュレーションです。投資助言ではありません。
- 価格は15〜30分ほど遅れます。約定が画面に出るまで最大30分ほどかかります。
- GitHubは、60日間リポジトリに更新が無いと定期実行を止めます。止まったら Actions 画面で再開してください。
